next4

Co-founder · App Store

Getting an agent to produce something is easy. The work is what checks it.

I build with AI agents constantly. Almost everything worth showing came from the structure around them, not the generation itself.

I run marketing as an organization, not a prompt.

next4's marketing has no team. A structured workbook holds seven content pillars, six channels and the weekly schedule; agents run a Monday research scrape and email me each day's posts with full scripts and the assets to prepare. I work from the email, never a dashboard. 14 posts/week · TikTok, Instagram, LinkedIn, X, Facebook groups and page

The verification step has to be able to kill the work.

A finished TikTok script opened with "ChatGPT made up a number in the first thirty seconds." Before filming, the check re-ran the prompt and audited every figure against College Scorecard. It hadn't made anything up. The post was killed and replaced with a true story that argued better — that ChatGPT can't compare anything, stacking five aid figures from five different definitions in one column. Brief ships with the prompt used, the audit table, every source URL and its retrieval date

Research earns the right to cut a feature.

Chancing was the most-requested feature in the category and the least trusted — students asked for it and disbelieved it in the same thread. We built the percentage screen, looked at it, and deleted the number. A survey later confirmed the call: asked to keep only one feature, 75% of parents kept discovery; essay tooling, which the whole competitive set is racing to build, got 11 votes of 69. 1,226 Reddit comments coded · 69 parents and 15 students surveyed

Agents are confidently wrong, so review is a separate job.

I build through Claude Code in a fixed loop — written spec, task plan, subagent execution with the test first, then a review pass whose only job is finding what the builder missed. It has caught an eviction bug in list-shaping, a scoring measure quietly tracking family wealth, and a whitespace bug that passed its own unit test because the test runner kept a space the production build dropped. Engine and knowledge-base packages: several hundred tests
